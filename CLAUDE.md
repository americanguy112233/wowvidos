# Рилсы про World of Warcraft: Forever

Вертикальные ролики 1080×1920 для Reels/TikTok/Shorts. Владелец собирает их на Windows (PowerShell), проект лежит у него в `C:\Users\ameri\Videos\wow-video`.

## Как устроен проект

| Файл | Что в нём |
|---|---|
| `index.html` | вёрстка 6 сцен + стиль Warcraft (тёмные панели, золотые рамки, красные кнопки, шрифт Alegreya SC) |
| `scene.js` | анимация (GSAP, детерминированная `renderAt(t)`), субтитры, петля в конце, фон и искры |
| `voice.py` | текст озвучки `CUES`, движки голоса, словарь произношения `SPOKEN`, тайминги слов → `assets/timeline.js` |
| `audio.py` | эффекты + музыка (по умолчанию выключена, `-Music 0.3` в build.ps1 — тихо под голос) |
| `render.mjs` | покадровый рендер через Chrome (у каждого потока свой браузер — иначе на Windows зависает) |
| `build.ps1` | полная сборка: голос → кадры → звук → `wow-forever-ban.mp4` |
| `thumb.html` | обложки 16:9 и 9:16 |
| `assets/` | шрифты, `news/` (скриншоты, фоны bg_portal/bg_forest, логотип), `stickers/` (круглые значки в золотой оправе), `qr.js` |

Прошлые ролики лежат в отдельных ветках: `reel-ban-nick` (бан за ник), `reel-class-stats` (кем играет бета), `reel-graphics` (команды для графики), `reel-enchanting` (фарм зачарованием). Перед новым роликом сохраняй текущий `main` в ветку `reel-<тема>`.

## Правила для каждого нового ролика

- **~30 секунд, 6 сцен** — по умолчанию; если владелец просит другую длину (например 55 с), число сцен подбирается под неё. Хук в первые 0.5 с: кадр 0 уже полный (он же превью в ленте), удар/вспышка на 0.04 с.
- **Динамика первых 5 секунд (требование владельца):** 2–3 удара в первой сцене (счётчик/печать/тряска), склейка внутри первой сцены к ~1.7 с, смена сцены к ~3 с. Первая реплика короткая (~3 с).
- **Монтаж — смена кадра каждые 3–4 с (требование владельца).** Движок в `scene.js` (с ролика про зачарование): сцена = несколько `.layer` (A, B, C…), склейки на метках `|x|`, `|y|` в тексте реплики. Появление элементов задаётся разметкой: `data-fx` (pop/left/right/up/zoom/slam/punch), `data-mark` (на каком слове), `data-at` (задержка), `data-count="от,до"` (счётчик), `data-shatter` (рассыпается на метке). Если реплика длиннее ~7 с — добавь третий кадр. Для финала с QR вместо склейки — наезд камеры на QR.
- **Видео владельца:** клип нарезается ffmpeg в `assets/video/<имя>/f_0001.jpg` (30 кадров/с, кроп центра, ширина 900) и `assets/video/<имя>.wav`. В вёрстке: `<div class="shotz vid" data-video="<имя>" data-from="сек" data-rate="1|0.5" data-frames="N"><img …><div class="vtag rec">…</div><div class="vcap">…</div></div>`. `renderAt` ждёт загрузку кадра; звук клипа (при rate=1) тихо подмешивается в `audio.py`. Плашки: `.vtag` (rec / slow), подпись `.vcap`.
- **Эффекты в scene.js:** `flashAt` (вспышка), `speedAt` (линии скорости), `slamIn` (печать), `shake`, `pulse`, `glowC`, `typeOut` (печать консольной команды), шторка до/после (`P.w`), переходы камеры 0.5 с со вспышкой.
- **Субтитры** — берутся из `CUES` автоматически, текущее слово золотом. Весь важный контент сцен — выше y≈1350, субтитры в зоне 1405–1595, справа не заходить за ~940 px (кнопки соцсетей).
- **Петля:** в конце камера перелетает к первому кадру.
- **Голос:** Silero, `xenia`, без ускорения (`SILERO_TEMPO=1.0`), паузы до 0.35 с. Интонация — через запятые, «!» и «?» в тексте. Ударения — через `SPOKEN` в `voice.py` (`б+эта`, `фор+эвэр`, `дв+орф`); в субтитрах остаётся обычный текст. Цифры пишем цифрами — голосу они сами переводятся в слова. Латиницу в `CUES` не писать (Silero её не читает): «FPS» → «кадров», команды только на экране.
- **Факты** — только из новости и присланных материалов, сверять цифры.
- **Кодировка:** любой текстовый файл в Python открывать с `encoding='utf-8'` — на Windows по умолчанию cp1251, и кириллица в браузере превращается в «ромбики с вопросами». В `timeline.js` кириллица пишется кодами `\uXXXX`.
- Команды для владельца — строчными буквами (при русской раскладке PowerShell теряет заглавные), по одной.

## Концовка-воронка (обязательно с ролика после «кем играет бета»)

Последняя сцена ведёт в Telegram-бот **@goldfarm_xbot** (`https://t.me/goldfarm_xbot`, QR в `assets/qr.js`), где **тест на голдфармера**. Реплика в конце — тизер: о «запретных» методах фарма рассказано в боте, пройди тест. Сами методы в ролике не раскрываем — только интрига.

Образцы последней реплики (варианты, подстраивать под тему ролика):
- «А ты бы потянул голдфарм в Форевер? Пройди тест в моём телеграм-боте, а о запретных методах фарма я рассказал там же!»
- «Кстати, о запретных методах фарма я рассказал в телеграме. Наводи камеру и пройди тест на голдфармера!»
- «Хочешь фармить как топы? Сначала пройди тест на голдфармера, ссылка — в QR-коде. А запретные методы ждут внутри!»

На экране последней сцены (именно так, утверждено владельцем):
- заголовок-вопрос: **«ХОЧЕШЬ УЗНАТЬ ЗАПРЕТНЫЕ МЕТОДЫ ФАРМА?»**
- QR-код на бота
- кнопка **«@goldfarm_xbot»**
- подпись под кнопкой: **«пройди тест в tg»**
